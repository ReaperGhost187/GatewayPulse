Network Map

Configure the Winlink CMS gateway map shown on the Network Map tab. The service code is applied as a URL parameter so Winlink autofills the Service Code(s) box.

LP-100A / RF Monitoring

Read-only TelePost LP-100A serial monitoring (115200 8N1, poll command P only). Keep the meter on its Watts screen. Enabling requires the LP-100A collector installed under Service\Lp100Monitor. Restart the Gateway Pulse service after changing enable/port so the supervisor reloads.

Connection status appears after Test Connection or when monitoring is enabled.

Preferences

Choose which dashboard cards and Power System fields are visible. Monitoring, alarms, logging, and API output continue even when items are hidden. Active power alarms still appear in the main status banner if the Power System card is hidden. RF primary metrics (Forward, Reflected, SWR, Peak) are always shown when the RF card is visible.
